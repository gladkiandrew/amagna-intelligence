# Weekly rhythm

- **Monday** — brief for the week. Three priorities, not nine. Everything else gets
  an owner and a date.
- **Wednesday** — delivery review. The only question is "is anything slipping that
  a client would notice".
- **Friday** — memory pass. Consolidate the week's log into notes worth keeping and
  discard what was only true on Tuesday. See [[consolidation-discipline]].

The cadence matters more than any individual meeting. A week without the Friday
pass accumulates a month of unprocessed log, and recall quality drops with it.
