# Consolidation discipline

Capture is easy and compounding is hard. Three rules that keep memory useful:

- **Write the conclusion, not the narrative.** "We hold the floor because the two
  sub-floor accounts churned in seven months" is a note. "Discussed pricing again"
  is not.
- **One fact, one note.** A claim that lives in two files will diverge, and you will
  not notice until an agent cites the stale one.
- **A pass with no discards did not happen.** If nothing was deleted, nothing was
  judged.

The test of a memory layer is not how much it holds. It is whether recall returns a
decision or a pile.
